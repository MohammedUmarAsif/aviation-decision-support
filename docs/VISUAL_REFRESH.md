# Focused visual refresh

12 October 2026. Presentation-only refresh of the published Flight Review study.

Preserved the original blue, light-paper and amber palette; existing content, sources,
caveats, section anchors, native controls, evidence files and numerical results.
No dependencies, photos, synthetic research imagery or analytical metrics were added.

The opening now pairs its question with the top three existing delay-burden results.
The introductory explanation remains in a named disclosure. Typography, section spacing,
chart panels and the chronological process strip are more compact and consistent.
The review section pairs the original queue composition with a complementary view of
all eligible severe outcomes, using the same measured found/missed counts. A chapter
link is restored after asynchronous evidence rendering to avoid misplaced anchors.

# AI contributions and human review

This independent proof of concept is developed with AI assistance. I review and learn the implementation, validate analytical claims, and document decisions and remaining limitations. It is a work in progress and is not affiliated with NABLA Mobility.

The initial audit/tests/README predated this session; exact authorship was not established. The user supplied the problem, scope, preferred stack, evidence limits, transparency requirements and public publishing authorization.

AI researched sources, modified/generated implementation, tests, reports, CI and Docker; ran checks, interpreted results provisionally and handled authorized publication. Agent checks are execution evidence, not independent peer review or personal comprehension. Unchecked AI output is unverified; passing tests cannot establish aviation suitability.

| Item | Human evidence | State |
|---|---|---|
| Problem scope, disclosure and publication | Explicit user request | User-directed |
| Rate versus total delayed flights | User correctly explained why 10% of 1,000 exceeds 20% of 100 in count | Basic distinction demonstrated |
| Minutes of burden and investigation choice | Explanation provided; no recommendation explained back | Pending |
| Python/SQL implementation and exclusions | Exercises available; no personal code review demonstrated | Pending |
| Chronology, baseline and uncertainty | Agent-generated/executed experiment | Personal review pending |
| Recommendations, CV bullets and interview script | AI drafts | Personal approval pending |

Do not infer independent coding, Python mastery or approval of all methods. The next review should trace a denominator test, recompute a result and explain a trade-off. Human value comes from questioning evidence and communicating meaningful recommendations; broader project decisions still need that personal review.
